# Provenance

This directory contains small, sanitized records retained to document how the manuscript-facing workflows were reconstructed from the original analysis environment.

The public repository intentionally does not include raw sequencing data, BAM/VCF/RDS objects, clinical identifiers, internal HPC paths, allocation identifiers, usernames, or other patient/institution-specific source material.

The executable scripts in `wes/` and `scrna/` are the manuscript-facing analysis workflows. The files under `provenance/` are supporting evidence only and are not required to rerun the cleaned workflows.
